# 우선 예약처 연동 조사

확인일은 2026-11-20이며 GitHub 이슈 #4의 조사 기록이다. 이 문서의 지원 범위는 확인한 자료를 기준으로 한다. 자료 접근 실패와 공식 API 부재는 구분한다. 실제 빈자리 수집기는 코트·이용일·시작/종료·예약 상태를 공식 화면과 대조한 뒤 활성화한다.

| 예약처 | 확인한 데이터 | 현재 제공할 수 있는 범위 | 추가 확인 |
| --- | --- | --- | --- |
| 부천 종합운동장 | 목록에 시설명·접수상태가 있다. 검색에 수집된 공식 상세 안내에는 13면, 2시간 단위 대관, 매월 20일 오전 10시 다음 달 접수 안내가 있다. 이번 확인에서 상세 페이지 직접 조회는 시간 초과로 끝났다. | 공식 예약 링크. 오픈 일정은 최신 상세 안내·해당 월 공지 재확인 후 등록한다. | 특정 코트·이용일별 잔여 슬롯의 응답 경로, 비로그인 조회 여부, 공식 API 제공 여부와 호출 조건. |
| 광명시립 | 일반예약 공개 달력에 날짜별 예약 가능·불가가 있고, 안내에서 일반·관내예약을 구분한다. 목록에 11월분 예약 안내가 있다. | 공식 예약 링크. 대상 월과 일반·관내 오픈 시각을 해당 공지에서 확인한 뒤 오픈 알림을 등록한다. | 특정 코트·시간대 데이터, 접수 유형별 공개 범위, API 및 자동 조회 조건. |

부천의 시설 목록 상태와 광명의 날짜별 달력 상태를 시간대별 빈자리로 변환하지 않는다. 이번 조사에서 두 시설의 시간대별 공식 API 명세와 자동 수집 허용 조건은 확인하지 못했다. API 키를 받으면 제공처·명세·승인 상태와 실제 응답을 대조한다. 키가 없거나 시간대 API가 없으면 공개 화면 수집 경로를 검증한다. 조회 경로를 확보하지 못한 시설은 오픈 알림·공식 링크만 지원한다.

## 근거와 남은 검증

- 부천의 운영 안내는 검색 결과에 수집된 공식 페이지에서 확인했다. 원문에 도달하면 대상 월의 변경 공지와 시간·코트별 예약 현황을 다시 확인한다. [부천 시설 목록](https://reserv.bucheon.go.kr/site/main/lending/lendingList?cp=1&inst_cate=0103&listType=list), [종합운동장 안내](https://reserv.bucheon.go.kr/site/main/lending/lendingDetail?cp=1&inst_cate=01&lending_info_seq=115&listType=list&pageSize=16)
- 광명은 일반예약 달력과 시설 안내를 열어 확인했다. 동절기·하절기 이용 시간이 다르고 관내 예약에는 자격 조건이 있으므로 접수 유형별로 모델링한다. [광명 일반예약 달력](https://reserve.gmuc.co.kr/user/tennis/tennisReservation.do?menu=d&menuFlag=T), [예약 안내·공지](https://reserve.gmuc.co.kr/user/tennis/tennisMain.do?menuFlag=T)
- 공공데이터포털에서 찾은 경기도 테니스 시설 현황은 위치·시설 메타데이터다. 시간대별 실시간 예약 응답을 대신하는 자료로 사용하지 않는다. [경기도 공공체육시설 현황](https://www.data.go.kr/data/75023/linkedData.do)
- 두 사이트의 `robots.txt`는 이번 웹 조회 도구에서 열리지 않았다. 응답 내용과 자동 조회 허용 여부는 미확인이다. 공개 접근과 API·자동 조회 정책은 각각 실제 제공처 안내로 확인한다.

## 다음 작업

1. 개발에서 제공처별 API 명세 또는 공식 예약 화면의 시간대 응답을 확보하고, 가능한 자리·마감·공개 전을 소규모 표본으로 대조한다. 조회 실패는 별도 상태로 기록한다.
2. 운영기관 정책에서 자동 조회 허용 범위와 호출 제한을 확인한다. 제공처에 별도 신청이 필요한 경우 사용자가 신청하고 개발에서는 필요한 필드를 안내한다. 기관 연락은 아직 수행하지 않았다.
3. 시설별 최신 오픈 공지를 확인해 이용 기간, 일반·관내 유형, 출처와 확인 시각을 저장한다. 이번 문서에 기재된 월간 안내만으로 향후 오픈 일정을 자동 생성하지 않는다.
4. 데이터 범위가 검증되면 마일스톤 M1의 시설별 지원 방식을 갱신하고 M3 수집 어댑터에 반영한다. 현재 M1은 진행 중이다.
